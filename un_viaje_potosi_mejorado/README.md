# Un viaje al pasado de Potosí — versión mejorada

Esta versión reúne el diseño, los estilos y la lógica en un solo archivo `index.html` para que sea más fácil de abrir.

## Cómo usarla
1. Extrae la carpeta completa.
2. Abre `index.html` con doble clic.
3. No muevas la carpeta `assets`, porque contiene las imágenes.

## Qué se mejoró
- Encabezado superior más fuerte con logo/emblema.
- Portada más completa.
- Episodios mejor presentados.
- Lector con mejor estructura.
- Actividades ampliadas con varias preguntas y resumen final.
- Archivo HTML autosuficiente (CSS y JavaScript integrados).
